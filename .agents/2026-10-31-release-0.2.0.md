# 0.2.0 release metadata alignment — 2026-10-31

## Objective and status

Align package/native source versions, release notes, documentation, and release
checks after the SDK update. Completed for source/metadata and local .NET
validation. Native regeneration with the new version metadata remains pending on
macOS before final package preparation/publication.

## Decisions made

- Selected 0.2.0 as a coordinated minor release for the SDK/dependency and release
  tooling changes. The previously suggested 0.1.41 would have been a patch.
- Set all four NuGet packages to 0.2.0 through Directory.Build.props with an empty
  suffix. Centralized updated PackageReleaseNotes there; removed the MAUICross
  override and obsolete commented version overrides in the package projects.
- Set the Android native module version to 0.2.0 and both iOS configurations'
  MARKETING_VERSION to 0.2.0. Incremented all Xcode CURRENT_PROJECT_VERSION
  settings from 1 to 2; dylib ABI versions were preserved.
- Added CHANGELOG.md with the unreleased 0.2.0 changes and validation caveats.
  Updated README installation examples, SDK maintenance instructions, macOS
  preparation guidance, and multiline C# call formatting.
- Replaced obsolete 0.1.0-preview.1 release instructions with the current version
  process, native regeneration requirement, Windows-inclusive packaging guidance,
  test commands, and manual publication gate for 0.2.0.
- Updated CI to JDK 21, explicit .csproj/.slnx paths, and restore/build/VSTest for
  the existing Windows test project. Kept CI manual and publication manual.
- Did not add the previously discussed warning suppression/report guard, since
  the user did not want that intervention. Known warnings remain documented.
